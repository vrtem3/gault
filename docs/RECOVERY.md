# Восстановление файлов без Gault

Нужны бинарный `.age` и **точная секретная фраза**. Сам сайт, backend, аккаунт и интернет для расшифровки не требуются. При утрате фразы у Gault нет запасного ключа.

Программы для Windows/macOS скачивайте только из официальных [релизов age](https://github.com/FiloSottile/age/releases) или [релизов rage](https://github.com/str4d/rage/releases), выбирая ОС и процессор. Текущая автоматическая матрица macOS использует age **1.3.2**, rage **0.12.1**, Typage **0.3.1**; актуальность стабильных версий проверена 19.10.2026. Спецификация бинарного формата: [C2SP age v1](https://c2sp.org/age). Версия программы и версия формата — разные обозначения.

## macOS — Terminal

Откройте Terminal в папке с архивом либо указывайте полные пути. Примеры предполагают age/rage в PATH; иначе используйте явный путь к распакованной программе. Выберите одну команду, новое имя результата и введите фразу в защищённый запрос самой программы:

```bash
age -d -o "восстановлено.zip" "архив с пробелами.zip.age"
rage -d -o "восстановлено.zip" "архив с пробелами.zip.age"
```

После успешного завершения сравните с доверенным оригиналом:

```bash
shasum -a 256 "исходник.zip" "восстановлено.zip"
```

Совпасть должны обе суммы. Для проверки большой копии места должно хватать на исходник, `.age` и результат. Команда восстановления не удаляет `.age`.

## Windows — PowerShell

Распакуйте официальный архив. Откройте PowerShell в папке с `age.exe` или `rage.exe`; поместите тестовый `.age` рядом либо укажите его полный путь. Выберите одну из команд:

```powershell
.\age.exe -d -o "восстановлено.zip" "архив с пробелами.zip.age"
.\rage.exe -d -o "восстановлено.zip" "архив с пробелами.zip.age"
$LASTEXITCODE
Get-FileHash -Algorithm SHA256 -LiteralPath "исходник.zip", "восстановлено.zip"
```

После age/rage код завершения должен быть `0`; проверьте его сразу после команды, прежде чем запускать другую внешнюю программу. SHA-256 сравнивается с доверенным исходником или ранее записанной суммой. Один хэш без эталона не доказывает правильность восстановления. Пути с пробелами/кириллицей заключайте в кавычки; имя результата должно отличаться от исходника.

Синтаксис SHA-256 соответствует [официальной документации Get-FileHash](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/get-filehash).

**Нативный ручной прогон Windows пока отложен.** Эти инструкции подготовлены по официальным интерфейсам CLI и PowerShell; macOS/OPFS не подтверждают работу системного диалога и ConPTY на Windows.

## Происхождение программ и ограничения

Установщик тестовых CLI Gault сверяет SHA-256 архивов с закреплёнными digest официальных GitHub release assets. Это подтверждает совпадение выбранного архива с опубликованной суммой; checksum и архив из одного источника не являются независимым доказательством при компрометации источника. Не используйте случайные зеркала и не обходите предупреждения ОС без проверки происхождения. Непроверенные подписи/attestations в этой инструкции не заявлены.

Не помещайте секрет в аргументы, переменные shell, историю, логи или скриншоты. Регистр, пробелы и Unicode значимы; фраза не нормализуется. Age не сохраняет исходное имя автоматически и не скрывает внешнее имя файла.

Неверная фраза, повреждённый байт и усечение приводят к ошибке. CLI может оставить частичный выход: его нельзя считать проверенным или использовать вместо оригинала. Не удаляйте `.age` и оригинал до успешного завершения и проверки содержимого/SHA-256.

Если браузер не поддерживает файл (ASCII armor, ключи-получатели, scrypt logN19–20), используйте age/rage с исходными параметрами. Не уменьшайте KDF и не исправляйте байты контейнера ради совместимости. Подробности — [RAGE_COMPATIBILITY.md](RAGE_COMPATIBILITY.md).
