# Следующие этапы

Сейчас развивается и проходит приёмку только криптографическое ядро самостоятельного шифратора. Кабинет, регистрация, серверный API, SMTP, статистика и новые пользовательские функции отложены до завершения этого этапа. Их исходники сохранены; API и его задания выключены, данные кабинета не публикуются.

План обновлён по чек-листу безопасности и надёжности. Открытые задачи находятся в локальном `TODO.md`, который не публикуется в GitHub; устаревшие ТЗ удалены после переноса требований. Кодовые доработки и малые автоматические проверки выполнены, домен подключён с HTTPS; ручная приёмка отложена пользователем. Результаты: [SECURITY_RELIABILITY_REPORT.md](SECURITY_RELIABILITY_REPORT.md). Профиль совместимости, неизменяемые образцы, проверки сбоев и потоковой обработки описаны в [истории изменений](../CHANGELOG.md). [Решение для rage logN=19–20](RAGE_COMPATIBILITY.md) сохраняет браузерный предел 18 и восстановление CLI без ослабления KDF; расширенный браузерный режим пока только предложен.

После приёмки криптографического ядра отдельным этапом планируются:

- Возвращение кабинета на отдельном origin `account.gault.ru`, проверка авторизации и API, миграций и восстановления БД.
- Настройка SMTP, подтверждения email и сброса пароля; пароль аккаунта не станет ключом файлов.
- Отдельное решение о добровольной статистике и сроках хранения. Текущий шифратор не отправляет события.

В текущий этап также не включены:

- Реальные облачные адаптеры, OAuth, хранение provider credentials и пересылка файлов.
- Google Drive, Яндекс Диск, Dropbox, iCloud, S3, SFTP/FTPS, Битрикс24 Диск/SSO.
- Работа с CRM, корпоративные роли, общий доступ, биллинг.
- Файловый менеджер, редактирование/предпросмотр содержимого.
- Desktop-приложение и дополнительные recipient/recovery-ключи.

При появлении удалённых токенов нужен отдельный дизайн шифрования хранения с ротацией ключей и аудитом. `StorageProvider` уже задаёт upload/download/delete/list/stat, но интерфейс не обещает работающих подключений.

Репозиторий [vrtem3/gault](https://github.com/vrtem3/gault) хранит код и пользовательское описание; GitHub Actions отключён, деплой выполняется напрямую по SSH. Шифратор доступен на `https://gault.ru`; подключение домена и малая проверка опубликованной поставки завершены 19.10.2026. Нативные Windows-диалоги и реальные смартфоны остаются непроверенными. Успешный тест ≥30 ГБ требует отдельного подходящего ПК и нового запроса пользователя; сейчас его не запускать и поддержку этого размера не заявлять.
