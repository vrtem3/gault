# Изменения исходного кода Gault

Репозиторий открыт для проверки реализации. Текущий этап — самостоятельный локальный шифратор; кабинет, API, статистика и облачные интеграции отложены. Уязвимости направляйте через [приватный канал](SECURITY.md), без пользовательских файлов и секретов.

Сохраняйте age v1 и закреплённый Typage. Не добавляйте собственные KDF/контейнеры, не уменьшайте scrypt и не повышайте браузерный бюджет без отдельного обоснования, измерений и совместимости. Не меняйте и не пересоздавайте frozen-контейнеры 0.1.0. Криптозависимости нельзя обновлять или автоматически сливать без повторной межреализационной проверки.

Изменение должно быть минимальным, с актуальной документацией и подходящими автоматическими проверками. Для затрагивающих ядро изменений нужны typecheck, unit/fuzz, малые browser/CLI проверки и SHA-256 восстановленных данных; для PWA — работа старых вкладок, офлайн и ошибки precache. Команды и ограничения приведены в [TESTING.md](docs/TESTING.md), проверка сборки — в [RELEASE.md](docs/RELEASE.md).

Проверки выполняются локально. Не добавляйте workflow GitHub Actions, автоматический деплой или публикацию задач из локального TODO. Не запускайте большие тесты без прямого разрешения владельца. Прикладывайте версии и обезличенные результаты; не публикуйте `.env`, ключи, БД, отчёты браузера, реальные файлы или скриншоты секретов.
